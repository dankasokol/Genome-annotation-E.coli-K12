# Локальные наборы RegulonDB

Для проекта скачаны восемь наборов Release 14.5 с датой в заголовках `06-09-2026`: `GeneProductAllIdentifiersSet`, `OperonSet`, `TUSet`, `PromoterSet`, `TerminatorSet`, `RISet`, `EvidenceSet` и `RegulatorSet`.

Исходные TSV сохраняются здесь без изменений, но `.gitignore` исключает их из репозитория. В их заголовках приведены условия использования и ограничения на интеграцию с другими базами. Перед самостоятельным распространением или интеграцией следует свериться с указанными в самих файлах условиями. Общая лицензия проекта этим данным не назначается.

Выпуск Bakta собирается и без этих наборов. Ноутбук `06` записывает только имена файлов, наличие и SHA-256 в `results/release_v1_bakta/qc/regulondb_manifest_local_only.tsv`.
