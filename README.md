# **Аннотация генома E. coli K-12 MG1655**

В проекте выполнили структурную и функциональную аннотацию бактериального генома, идентичного референсу NCBI `NC_000913.3`. Основной каталог получили с помощью Bakta и дополнили результатами eggNOG-mapper и InterProScan. NCBI использовали для проверки, а результаты PHASTEST и DefenseFinder представили отдельными геномными слоями.

Все 23 компонента защитных систем совпали с Bakta по координатам и белковой последовательности. При сравнении с NCBI два соответствия остались на ручную проверку. Дополнительные функциональные признаки получили для 210 из 234 гипотетических белков; наличие этих признаков не приравнивали к установлению функции.

## **Файлы итогового выпуска**

- [Функциональный каталог](results/release_v1_bakta/tables/bakta_CDS_functional_annotation.tsv): 4315 кодирующих последовательностей с дополнительными сведениями о функциях и связях с защитными системами и профаговыми областями.
- [Все геномные признаки](results/release_v1_bakta/tables/bakta_all_features.tsv): 9378 записей, включая описание генома, гены, кодирующие участки и РНК. Записи генов и связанных с ними кодирующих участков учтены отдельно.
- [Структурная аннотация](results/release_v1_bakta/ecoli_bakta_primary.gff3) и [запись GenBank](results/release_v1_bakta/ecoli_bakta_primary.gbff): исходные результаты Bakta без изменения содержимого.
- [Сводка проверки](results/release_v1_bakta/qc/summary.json) и [контрольные суммы](results/release_v1_bakta/qc/checksums.tsv): основные показатели, ограничения и сведения для проверки целостности файлов.

Координаты в таблицах начинаются с 1, обе границы включены. Копии исходных файлов в составе выпуска сохранены для его отдельного использования.

## **Вычислительная среда и воспроизводимость**

Аннотацию выполнили в Docker с Bakta 1.12.2 и облегчённой базой версии 6.0, использовав четыре потока. Параметры запуска и сведения о локальном образе сохранили в [описании вычислительной среды](provenance/bakta_run.json). Принадлежность зарегистрированного образа первоначальному запуску независимо не подтвердили. Базу данных подключали отдельно от образа.

Версии основных библиотек Python зафиксировали в [файле окружения](environment.yml). Все пять ноутбуков выполнили последовательно без ошибок. Проверку сохранённых данных и выпуска реализовали в [проверочном скрипте](scripts/validate_project.py).

Сборка воспроизводится из сохранённых результатов. Полные исходные ответы PHASTEST и DefenseFinder отсутствуют, что ограничивает повторение первичных анализов. InterProScan охватил только 234 исходных гипотетических белка. Полную аннотацию спейсеров CRISPR и реконструкцию метаболизма не выполняли; биологическую активность предсказанных систем экспериментально не подтверждали. Наборы RegulonDB оставили локальными и исключили из Git.
